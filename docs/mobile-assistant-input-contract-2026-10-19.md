# 系统页面文字与外部输入契约

2026-10-19，第二批恢复实施。W05/F03/S01/S07 的增量；整版 W00–W21/F01–F22/A01–A28/S01–S12 仍未完成。

## 输入交付

分享按批次经 `ShareBatchIntake` 串行转换，冷启动批次先于初始化期间的暖分享；同时待转换最多8批。转换错误不会阻塞后续批次。分享与通知接入 `DeepLinkService` 的统一队列，最多8条、总计16MiB编码字符；每批最多12项、合计16000文字字符。满队列拒绝新输入并提示重新分享，不驱逐已有输入。通知按类型和目标去重。深链保留既有入口协议，纯助手导航不会替换已有输入。

`AssistantEntryDelivery` 只负责导航和草稿交付，没有发送消息、调用模型、执行工具的入口。每条输入有独占租约；确认后重新检查当前页面可见、已解锁、忙碌/恢复状态、控制器与会话身份、草稿和附件版本、输入身份。过期回调不能消费后来输入。通知在数据库等待之后再次检查可见性；目标不存在给出提示。通知只导航，不能自动批准动作。

分享和页面文字必须经过可编辑核对页。加入时追加到当前草稿并保留已有附件，不新建会话或自动发送；取消会暂停该输入，只有明确重试才重新展示，丢弃只移除对应输入。应用锁查询或验证失败按未解锁处理；前台、路由和导航栈共同控制交付，不弹出未保存页面。

## 单次页面文字

- 系统助手服务默认同时禁用 AssistStructure 和截图。用户在真实系统面板点击“读取本页文字（仅本次）”后，当前会话仅请求一次 AssistStructure；发出请求立即恢复默认禁用标记。回调最多等待8秒，关闭后结束该 session，后续手势使用新实例。
- 只处理主活动的系统结构，来源包取自系统 activityComponent，应用名称由 PackageManager 获取；不信任页面提供的来源标签，不读取 AssistContent extras、截图或后台页面。
- 遍历最多4个窗口、256个节点、16层、8000文字字符。跳过被系统阻止、隐藏、有输入类型或可识别为 EditText 的节点及其子树。标明截断，不能宣称过滤能识别所有第三方自绘敏感内容；正文仍可能包含敏感信息。
- 原生交接槽只在进程内存中保留一条内容，不覆盖尚未处理内容，不写文件、偏好、日志或URL。生命周期使用 elapsedRealtime，最多两分钟；Dart队列与核对页另有单调计时，时钟回拨不延长保留。ACK按精确ID，队列满时原生保留到期并等待后续真实事件重试。
- 原生读取、交接以及加入草稿都重新核对默认助手角色、激活与锁屏状态。离开前台会清空已打开的页面文字核对框；过期后不得加入。原始快照过期，用户明确加入的普通草稿仍按既有草稿机制保存。
- 文字来源和采集时间随确认内容加入草稿，并明确页面内容不授予操作权限。最终发送仍由用户操作。

## 验证边界

`assistant_entry_checks.dart` 的合同在 Android Dart isolate 中执行，固定数据和受控 Future 用于竞争、失效、批次与边界检查；不写真实用户数据库。

`verify_assistant_entry_ui_emulator.py` 使用生产队列、协调器、核对页和四导航，内存草稿与隔离通知目标；应用锁状态是夹具模拟，不能冒充实际生物识别。

`verify_assistant_context_ui_emulator.py` 仅允许读取专用 debug 活动的固定公开文字和密码测试框，测试真实系统 AssistStructure、来源、过滤、FLAG_SECURE、截断及编辑确认；恢复原系统助手。该活动只存在于 debug source set，不是公开生产捕获接口。

实际结果、APK与证据哈希见恢复实施记录。未实际通过的场景不算完成。当前不以此证明中文声学识别、真实录音/TTS、连续会话、实时多模态、安全锁屏、多厂商、其他API、ARM64或完整系统分享插件端到端支持。

保护处理的实现依据：[AOSP AssistStructure](https://android.googlesource.com/platform/frameworks/base/+/HEAD/core/java/android/app/assist/AssistStructure.java) 在 secure window 上阻止 Assist 层级，并标记根节点 assistBlocked；本项目遵从该标记，不尝试恢复被保护的内容。源码依据不能代替设备证据。
