# 历史会话页 UI 审计（2026-09-26）

截图：`artifacts/ui-shots/history_shots_test.dart`（393×852 @2x，动效关闭，示例数据通过 `loadConversations` 注入）。
`history_page.dart` 无 WIP 改动；`section_card.dart` 属 WIP，不改组件本身，只在本页决定是否继续使用它。

## 问题

| 编号 | 问题 |
| --- | --- |
| H1 | 每条会话都是一张独立描边卡片，行高约 80，屏幕只放得下 6 条，视觉很重 |
| H2 | 左边缘不齐：搜索框和筛选胶囊在 16，会话卡片在 12（列表 8 + 卡片外边距 4） |
| H3 | 浅色模式搜索框几乎没有底色（透明玻璃），和设置页 T2 的胶囊搜索不一致 |
| H4 | 筛选胶囊靠描边区分，选中态是品牌色描边 + 浅底，未选中是白色半透明描边 |
| H5 | 分组计数小徽标带描边 |
| H6 | 相对时间不一致：「12 分钟」「2 小时」没有「前」，「3 天前」有 |

## 方案（顺序 V1→V5）

- V1：对齐与节奏——列表左右统一 16；分组标题上间距统一，首组与筛选行之间留 12。
- V2：同组会话合并为一张圆角 16 的填充卡片（无描边），组内行之间用缩进细分隔线；行高收紧到约 64，前导图标缩小并放入浅色圆形底。不改 `SectionCard` 组件本身。
- V3：搜索框改为与设置页一致的胶囊填充样式。
- V4：筛选胶囊去描边，选中用品牌浅底 + 品牌色文字，未选中用浅填充；分组计数徽标去描边。
- V5：相对时间统一加「前」（「12 分钟前」「2 小时前」），纯文案，不改排序或分组逻辑。
