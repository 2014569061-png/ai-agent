## 方案（顺序 W1→W6）

- W1：对齐——列表与筛选行左右 16；卡片圆角 16（只给 `SectionCard` 传参）。（K3、K6）
- W2：类型标签改为中文短标签（`taskTypeLabel`，如「问题修复」），浅色低饱和胶囊；标题已以该标签开头时不再重复显示标签。（K1）
- W3：元信息行 projectKind 为 unknown 时不显示。（K2，只改展示）
- W4：筛选改为与历史页一致的无描边填充胶囊（选中品牌浅底 + 品牌字，数字弱化），待审批红点保留。（K4）
- W5：待审批提示条去描边，按钮改为琥珀浅底胶囊（同仪表盘 U4）。（K5）
- W6：搜索框改为胶囊填充样式（同历史页 V3）。（K7）
