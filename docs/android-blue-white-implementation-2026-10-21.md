# Android 蓝白 UI 改版交付记录

日期：2026-10-21。

本次以用户最早提供的四张图片为视觉参考，落实到 Android 应用。沿用图 2 的欢迎页和两行输入区、图 4 的项目分组、图 1 的任务优先级与图 3 的对话布局；没有采用随后生成的四屏概念图作为视觉基准。

## 已完成

- 新增独立的 `MobileTheme`，应用于移动端主题分支，统一浅蓝白画布、中文字体、圆角、导航选中态、表单、筛选和浮层。
- 首页替换原工程文案与功能网格，采用柔光轨道标识、简短欢迎语和三个建议入口。
- 顶栏精简为会话入口、NEXUS / 当前会话标题、创建对话；标题仍可打开会话配置。
- 输入区改为两行，保留多行文本、附件、真实模型选择和发送。执行模式、审批策略、前台单句语音、代码块、用量与上下文可从具名菜单进入。
- 手机运行中的停止按钮直接可见；暂停仍可从菜单访问，继续、补充要求沿用实际运行状态与控制器。
- 对话采用浅蓝用户气泡、助手身份标记和易读正文；执行记录使用圆角分组，原有工具审批回调继续保留。
- 底栏固定为“助手 / 任务 / 工作区 / 我的”，保留独立导航栈、草稿和返回行为；键盘弹出时收起底栏。
- 任务默认展示待处理，保留最近任务和独立未读收件箱；列表说明、全部已读、定时任务及工作流进入更多菜单。
- 工作区提供搜索、最近项目和成果入口，右上加号包含模板新建、目录导入和 ZIP 导入；项目主页与原有项目选择行为均可达。
- “我的”采用大标题和圆角分组，保留搜索、模型配置、数据、设备、备份、外观和其他原有设置。现有设置分组仍沿用业务结构。
- 统一公共页头、卡片、列表和底部面板；为成果中心、浏览器、费用账本、指标、远程验证、搜索、系统助手、模板导入和系统编辑器页面补齐公共布局。
- 保留工作区其他未提交工作。桌面入口继续应用 `DesktopTheme`，未强制 Android 进入桌面布局。
