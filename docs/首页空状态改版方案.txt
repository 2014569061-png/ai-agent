# 首页空状态改版方案(方案 A:紧凑胶囊网格)

> 版本 v1 · 待评审
> 范围:仅聊天页空状态(无消息时的首页),不改对话页其他部分。

## 一、背景与目标

当前空状态页视觉过重:三张全宽大卡(高约 110dp)占据半屏,紫色渐变圆底图标与云朵背景抢色,标题 34dp 纯黑加粗,整体"又大又黑又粗"。

目标:**简洁、美观、轻盈**——让背景图当主角,UI 退后;建议项从"三个大按钮"变成"轻盈的建议标签"。

## 二、现状问题

| # | 问题 | 位置 |
|---|------|------|
| 1 | 建议卡全宽、高 ~110dp,三张占半屏 | `_QuickActionCard` |
| 2 | 图标为紫色渐变圆底(直径 ~48dp),与背景抢色 | 同上 |
| 3 | 标题 34dp 纯黑粗体;卡标题 17dp 粗体,层级失衡 | 标题区/卡片 |
| 4 | 每卡右侧 chevron 冗余 | 同上 |
| 5 | 卡片间距大(10)+ 卡内边距大,页面松散 | 同上 |

## 三、设计规范(精确值)

### 3.1 标题区

| 项 | 现状 | 新值 |
|----|------|------|
| Logo 尺寸 | ~72 | 56 |
| 问候语字号/字重 | 34 / bold 纯黑 | **22 / w600 / onSurface 90%** |
| 副文案 | 无 | 新增一行:`直接输入需求,或试试这些`(13 / 提示色) |
| Logo 与标题间距 | 大 | 收紧(24) |

### 3.2 建议项(2×2 网格)

| 项 | 现状 | 新值 |
|----|------|------|
| 布局 | 单列全宽 3 张 | **2×2 网格**(GridView/ Wrap,spacing 10) |
| 单项高度 | ~110 | **44** |
| 底色 | 玻璃白 + 阴影 | 半透明白玻璃(与输入框同材质,无独立阴影) |
| 圆角 | 大圆角(~24) | 22 |
| 图标 | 紫渐变圆底 48 + 白 icon 22 | **线性图标 18,单色**(onSurface / primary),无底色 |
| 文字 | 17 / bold | **14 / w400 / onSurface** |
| chevron | 有 | **删除** |
| 内容 | 图标+文字+chevron | 图标+文字,水平居中排布 |

### 3.3 建议项内容(维持现有 3 项,第 4 格补充"解读工作区")

解读项目 🔍 / 修复问题 🔧 / 头脑风暴 💡 / 解读工作区 📄
(第 4 格让 2×2 满格;若不想加第 4 项,则退化为 3 项 + 1 个空白占位,仍推荐加第 4 项。)

## 四、技术方案

### 4.1 组件结构

```
ChatEmptyState(StatelessWidget,重写 build)
├── logo(Image.asset, 56)
├── 问候语 Text(22/w600)
├── 副文案 Text(13)
└── GridView.count(
    crossAxisCount: 2,
    shrinkWrap: true, physics: NeverScrollableScrollPhysics,
    mainAxisSpacing: 10, crossAxisSpacing: 10,
    childAspectRatio: ~3.2   // 保证高 44
    children: suggestions.map(_SuggestionChip))
```

`_SuggestionChip`(新私有 widget,替代 `_QuickActionCard`):

```
InkWell(onTap: onSuggestionTap)
└── Container(高 44,玻璃:白 alpha 0.55(深色:白 0.08),圆角 22,
             细描边 onSurface alpha 0.08)
    └── Row(mainAxisSize: min, center)
        ├── Icon(线性, 18, onSurface)
        └── SizedBox(8) + Text(14, w400)
```

### 4.2 涉及文件与改动

| 文件 | 改动 |
|------|------|
| `lib/presentation/widgets/chat_empty_state.dart` | 重写 build;`_QuickActionCard` → `_SuggestionChip`;新增副文案;建议项列表扩为 4 项(带各自线性图标映射) |
| `lib/presentation/chat/chat_page.dart` | `_emptyState()` 的 suggestions 传入 4 项;`_fillSuggestion` 增加"解读工作区"的分支(等同解读项目:无工作区先选工作区) |

### 4.3 交互(不变)

点击建议 chip → `_fillSuggestion(text)`:
- "解读项目/修复问题/解读工作区":无工作区时先弹工作区选择,选完填充 prompt;
- "头脑风暴":直接填充输入框并聚焦。
不自动发送,与现状一致。

### 4.4 键盘适配(保留)

键盘弹起(keyboardVisible)时收缩 logo/标题区,仅保留建议网格——现有逻辑保留,参数随新布局调整。
