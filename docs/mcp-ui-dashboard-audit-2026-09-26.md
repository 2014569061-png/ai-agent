## 问题

| 编号 | 问题 |
| --- | --- |
| D1 | 顶栏分隔线下紧贴「待我处理」标题，没有上间距 |
| D2 | 分区间距不一：待办→性能卡约 36，性能卡→KPI 12，KPI→运行状态 24，运行→Token 28 |
| D3 | 性能卡标题「Console & Telemetry」+「LIVE」是英文，和全中文界面不一致 |
| D4 | 浅色模式下性能卡里的两个小格（活跃 Agent / 缓存命中率）没有底，深色有描边，两套样式 |
| D5 | 待办的操作按钮是实心亮蓝，两行并排时很抢眼，层级高于标题 |
| D6 | 「缓存命中率」出现两次且数值不同（性能卡 37%、KPI 40%），口径不同但没有说明 |

## 方案（顺序 U1→U5）

- U1：统一节奏——分区间距 24、区内 12；顶栏下留 8。
- U2：性能卡标题本地化为「实时用量」，LIVE 改为「实时」小胶囊。
- U3：浅色模式小格补浅底（文字色低透明度），与深色结构一致。
- U4：待办按钮降为浅色胶囊按钮（品牌色文字 + 品牌浅底）。
- U5：D6 口径问题只在 UI 上加区分（如「今日缓存命中率」/「7 日缓存命中率」），需确认两者口径后再改文案。
