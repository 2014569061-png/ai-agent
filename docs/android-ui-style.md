# NEXUS Android UI 规范

用户确认的持续默认风格，2026-10-21。适用于全部 Android 页面、嵌入视图、弹层与新功能入口。参考用户提供的四张蓝白界面：轻盈对话首页、浅蓝用户气泡、清晰执行过程、白色圆角项目分组。实际实现以 `lib/presentation/theme/mobile_theme.dart` 为共同来源。

## 视觉与信息层级

- 白色和浅冷灰为主体，主操作蓝色 `#0A59F7`，选中底色 `#EAF2FF`，主文字 `#182230`，次文字 `#667085`。
- 共享 `MobileCanvas` 提供低对比蓝白背景；内容表面保持实色白色。柔光只作背景点缀和少量浮层，不为普通内容添加厚阴影或重玻璃。
- 页面侧边距 20dp；间距使用 4 / 8 / 12 / 16 / 24 / 32dp。默认内容分组圆角 24dp、表单 18dp、按钮 16dp、弹层 28dp、输入区 24–28dp；小图标容器和代码标记按用途缩小。
- 中文系统字体；正文 15–16sp，次级正文 14sp，二级页标题 21–22sp，首页欢迎语 28sp。主要触摸目标至少 48dp。大字体自然增高，避免给文字输入区和列表行锁定高度。
- 每个页面突出一个主要操作。低频操作放入“更多”或底部面板；长说明、调用参数、费用与诊断详情渐进展开。权限、费用、数据与执行后果须在相关操作处清晰呈现。
- 同一空页面不重复展示相同的居中按钮和悬浮按钮；有悬浮按钮的列表应为末项预留滚动空间。搜索框需及时反映键入、清空和外部筛选变化，长标签保留完整内容的查看方式。
- 蓝色表示选择、主操作与运行强调；成功、警告、危险保留语义色并配文字/图形。未读、待处理、已完成、失败、部分完成与待核实保持原有业务含义。

## 实现选择

| 用途 | 默认组件 / 规则 |
| --- | --- |
| 页面与导航 | `NexusPageLayout`、`NexusPageHeader`，左上角打开统一侧栏，主入口为助手、任务、工作区、我的；首页底部仅保留输入区 |
| 内容分组 | `SectionCard`，使用默认圆角和实色表面；不逐页重新画装饰卡 |
| 设置分组 | `SettingsSectionTitle`、`SettingsGroupCard`、`SettingsTile`、`SettingsDivider`；分组自带外边距时，不重复添加横向边距 |
| 内容列表 | `NexusListTile`；文件、任务、项目用单列与逐级进入，保留长名称、路径的查看入口 |
| 搜索 | `NexusSearchField`，保留业务查询、提交、清空与长度限制；不固定高度 |
| 表单与按钮 | 原生 Material 控件继承 `MobileTheme`；无需重设字体、圆角、描边和主色 |
| 加载 / 空 / 失败 | `AsyncStateView` / `NexusAsyncContent` / `EmptyStateView`；局部操作失败可用 `NexusErrorNotice`，提供真实重试回调、保留已加载内容和可展开诊断 |
| 展开详情 | `NexusDisclosure`，默认只呈现当前动作、状态、简短结果 |
| 状态 | `NexusStatusPill` / `NexusStatusBadge`，保留语义、文字和非颜色提示 |
| 结果 | `ResultCardView`，保留查看、预览、导出、刷新和过期/冲突提示 |
| 弹层 / 确认 | `showNexusSheet` / `showNexusDialog` / `showConfirmAction`；适配键盘、安全区、返回手势与屏幕阅读器 |
| 配色 | `Theme.of(context).colorScheme` 或 `AppTheme.semanticOf(context)`；后者已接入手机主题，兼容原有公共组件 |
| 几何 | `MobileTheme.controlRadius/cardRadius/modalRadius(context)` 为共享组件提供平台区分；桌面保持原布局 |

普通交互沿用项目动效体系的约 180–260ms 轻量过渡，尊重减少动态效果设置。不得为页面装饰新增持续闪动。

### 手机动效第一版（2026-10-23）

- 手机公共轻量参数来自 `lib/presentation/motion/mobile_motion.dart`：按下 100ms、控件恢复 / 图标淡入 120ms、新消息 180ms、Sheet 进入 240ms / 退出 160ms。
- 用户新消息只在落点上移 6dp 并淡入，不飞行、不缩放；助手正文只保留首个 token 的淡入。历史、分页和流式追加不重播入场。手机流式内容使用自然高度，避免高度弹簧与滚动同时追赶。
- 手机 `NexusPressable` 取消光斑，默认松手平稳恢复；发送按钮轻按至 0.97。完成态没有装饰循环，运行态保留局部轻微呼吸，思考标题不扫描。
- 手机 Sheet 不过冲、不做拖拽缩放；使用单层路由遮罩，保留安全区、拖拽与显式确认约束。曲线对象跨帧复用并在销毁时释放。侧栏沿用原生 246ms 跟手抽屉，不为改时长重建导航。
- 减少动态效果时，上述手机消息、控件与面板立即更新。桌面的独立弹簧与光感保留。本轮没有替换所有页面路由及独立分段器的专用动画。
- 实际录屏与范围见 `docs/design-previews/android-second-pass-2026-10-23/motion-v1-implementation.html`。275 项相关检查通过；模拟器核对不能代替 ARM 真机 profile 性能验收或全部页面的动态验收。

### 手机动效流畅度修复（2026-10-23）

- 手机公共 Sheet 与对话框使用实色表面，不在移动面板上采样、模糊或折射背景。全局玻璃偏好仍保留，其他既有表面与桌面不因此改变。
- 手机 Sheet 在实际面板边界内使用 `RepaintBoundary`，让位移动画复用内容绘制；不缓存整个透明全屏，也不在每一行添加独立缓存。动态内容仍按自身状态更新。
- 不用延长时长、补帧或压低刷新率掩盖卡顿。当前面板仍为 240ms / 160ms；调试模拟器采样与生产真机验收分开记录。
- Android `screenrecord` 是可变帧时间戳，包含长静止时段。转码时使用当前 FFmpeg 支持的 `-fps_mode passthrough -enc_time_base -1`，不要把平均帧率当固定帧率；仅设置 `-fps_mode vfr` 仍可能被编码器默认时基量化丢帧。必须核对源 / 输出帧数和逐帧 PTS。
- 最新实录、对比及性能采样范围：`docs/design-previews/android-second-pass-2026-10-23/motion-v2-performance.html`。331 项相关回归通过，包括静态面板移动时不重复绘制。调试模拟器仍有超预算帧，未宣称真机稳定 60/120fps。

## 主要页面

- 助手：欢迎语、最多三个真实建议、多行输入；模型/Agent 与附件入口清楚。会话使用浅蓝用户气泡、适合长文的助手正文和默认折叠执行详情。
- 手机首页采用靠上居中的欢迎区：84dp 轻量光球、26sp / 400 欢迎语、细线图标与浅描边建议。输入区统一 20dp 侧边距，模型选择使用浅色胶囊；默认底色偏白，光感集中在欢迎区。保留用户自定义背景。未配置模型时避免重复提示；键盘弹出收起欢迎建议，系统返回优先关闭附件面板。
- 任务：优先待处理，其次进行中和结果。任务列表紧凑；审批说明动作、影响及允许/拒绝，不能把标记已读当作完成处理。
- 工作区：最近项目、创建入口、成果入口。项目内文件、Git 改动、预览、终端和交付逐级进入。
- 我的：按用途组织圆角列表，无头像营销卡、会员或不存在的账号/云同步入口。
- 其他页：模型与服务商、Agent、技能、MCP、记忆、个人上下文、知识库、提示词、定时任务、工作流、浏览器、成果、费用、运行记录、诊断、审计、设备、权限、保险箱、备份等沿用上表组件。

## 专用画布

终端输出保留深色等宽画布，但手机页头、更多菜单、配置表单和辅助键使用蓝白主题。代码编辑器保留等宽与完整编辑区域，外层页头、搜索/跳行、保存/引用和错误状态一致。Git 差异保留增删颜色，网页和自定义聊天背景保留用户内容。专用内容不构成整页另起一套样式的理由。

## 移动侧栏导航（2026-10-21）

用户已明确要求取消突兀的底部导航。手机默认采用左侧抽屉：顶部为轻量新建按钮，助手、任务、工作区三个紧凑主入口后直接展示最近会话；搜索通过图标展开，完整历史通过“全部”进入。“我的”和“助手与工具”固定在抽屉页脚；后者打开底部面板，提供 Agent、模型、MCP、提示词、运行与费用及会话工具。保持蓝白实色表面、浅蓝选中态、轻量遮罩与右侧圆角。

主页面左上角提供菜单，详情页保留返回按钮，并支持从左边缘滑出侧栏。每个主入口保留独立导航栈与草稿；系统返回先关闭侧栏，再返回详情，最后回到助手。待处理角标读取任务 attention 状态，不使用未读数替代。桌面布局沿用原有导航。

## 2026-10-22 全量实施精修规则增补

1. **页头与状态徽标**：`NexusPageHeader` 大标题收拢至 72dp 高度，标题字阶 28sp w500；状态徽标（`statusPill`）与主标题并排内联放置，禁止置于页头底部以防在密集模式或窄屏上被裁切。
2. **空态位置与阅读**（2026-10-23 更新）：手机 `EmptyStateView` 从内容区顶部布局，默认顶部留白 40dp；紧凑 / 普通图标底盘为 40/48dp。说明自然换行，不截断必要信息。创建入口与页头避免重复；桌面保留自身布局。
3. **列表水波纹与无障碍 Material 边界**：在 `NexusPageLayout` 或深底容器中，所有 `ListTile`、`CheckboxListTile` 等具备水波纹点击效果的项均显式包裹 `Material(color: Colors.transparent)`，防止水波纹被父级实底裁切并确保语义层级完整。
4. **边距与几何对齐**：全量 58 个页面端点统一使用 20dp 侧边距（`EdgeInsets.fromLTRB(20, ..., 20, ...)`）；分组卡片统一采用 24dp 圆角（`MobileTheme.cardRadius`），输入组件 18dp，按钮 16dp，最小触控高度不低于 48dp。
5. **多行长文本与折叠**：长说明、技术参数和原始 JSON 默认提供折叠面板或详情跳转，首屏仅保留核心决策依据与主要操作。

## 2026-10-23 精修规则增补

1. **配置入口减量**：服务商页面优先显示已配置项，一个添加入口收纳兼容 API、官方 API、模板与预设；空列表只提供一个主要添加动作。
2. **复杂表单渐进展开**：Agent 执行步数、采样与输出参数归入高级执行参数，标题附近显示当前摘要；实际工具授权仍可直接核对。项目位置、运行环境和 Git / 变更 / 远程信息按需展开，保留五个原有标签和所有原操作。
3. **权限说明完整可读**：`SettingsTile.wrapText: true` 用于授权或执行后果说明，标题与正文自然换行，不使用省略号代替必要告知。自动验证与修复可归入一个折叠组，展开后必须保留依赖条件、写入审批和次数限制。
4. **状态按真实含义表达**：设备快照用“最近检测”及真实时间，不用 LIVE 暗示持续更新；复杂终端状态放正文，避免挤压页头。运行详情首屏显示状态、耗时、用量和预计费用，原始指标与 ID 进入详情。
5. **失败与诊断分层**：局部失败先显示用户可读原因和可执行恢复动作，原始异常进入可选择复制的诊断详情。没有真实重试行为时不添加伪按钮。
6. **浮层生命周期**：从抽屉打开底部面板时预先捕获导航器与回调，面板内容使用自己的构建上下文。验证抽屉销毁后的重建、返回与草稿保留。
7. **帮助与技术信息**：动效诊断、完整备份清单、模板 JSON 示例、系统助手隐私帮助及账本原始编号按需展开；保留预算规则、估算限制、来源核对、危险确认和系统助手主动读取条件的就近告知。


## 第二轮细节精修（2026-10-23）

- 首页欢迎区不重复解释助手用途；模型选择器限宽，完整名称仍可通过提示和选择面板查看。
- 创建入口统一：例如 Agent 只保留一个创建按钮，再选择描述目标或手动配置。
- 列表图标底盘使用 36dp，点击目标仍至少 48dp，不以缩小触控范围换取紧凑视觉。
- 已完成任务优先展示结果，执行过程可展开；审批、失败和需要处理的状态不得随技术日志一起隐藏。
- 工作流显示步骤总数和需确认数量，完整步骤展开，实际执行前仍核对全部步骤。
- 日志页只常驻筛选与更多，复制、导出、清理在统一操作面板；清理仍经过原有确认。
- 文件编辑器跳行按需打开，保留未保存内容的返回保护。无记录账本不展示第一页的分页控件。
- 浏览器始终保留页头立即接管；自主浏览时才显示允许助手操作，准确告知临时会话及授权边界。

### 紧凑侧栏（2026-10-23）

- 顶栏提供搜索与关闭，搜索按需展开，准确标注“搜索最近对话”。新建入口不使用大面积底色。
- 主导航只强调选中文字及图标；当前会话使用浅灰整行选中。入口最小触控高度 48dp，保留任务待处理计数。
- 普通会话不重复气泡图标，置顶保留图钉；当天直接列出会话，跨日期时再显示分组。会话长按与更多菜单继续可达。

### 手机聊天细节补充（2026-10-24）

- 模型与执行选项使用轻量文字选择器，无独立白底胶囊；保留 48dp 触控和窄屏执行选项图标。
- 侧栏搜索采用 subdued 样式；搜索时隐藏主导航和固定底部入口，关闭时恢复。非当前会话可通过长按及语义自定义操作打开菜单。
