# Eta 参考改进：第一阶段（2026-10-20）

> 本文保留第一阶段的验收快照。下文列出的 5 项回归失败和两个门禁已在[第二阶段](eta-improvements-phase2-2026-10-20.md)处理并复核；当前结果以第二阶段记录为准。

本阶段按“运行语义 → 职责分离 → 数据处理”推进。借鉴 Eta 的职责划分，修改基于 NEXUS 现有实现；没有引入第二套 Agent Runtime，也未添加运行依赖。所有变更均为工作区增量修改，未提交或推送。

## 已落地

### 补充指令契约

运行开始前已排队的指令进入首个请求；响应过程中到达的指令在下一回合消费；完成检查期间接受的指令继续执行；封存后拒绝新指令。

原失败测试在开始前排队，却断言必须再发起第二轮。保留原有完成边界断言，将入队操作移动到实际 `beforeFinish` 回调；另加开始前入队与响应中入队两项回归。未放宽运行预算、取消、审批或完成判定。

### 核心职责分离

- `chat_tool_registry_builder.dart` 根据调用方传入的运行范围组装工具，不读取聊天状态，也不管理运行生命周期。
- `workspace_tool_set.dart` 供聊天与后台执行共用；同一组文件工具共用读前写沙箱。调用方原有 allowlist、只读限制及审批继续生效。
- `run_tool_settings.dart` 统一读取文件/终端独立开关与旧组合开关的兼容逻辑；旧 `chat_controller.dart` 导入仍可访问 `ToolSettings`。
- `android_device_control_bridge.dart` 管理 Android MethodChannel 与权限通道快照；设备工具继续管理预览、审批票据及执行。旧导入路径保留桥接类导出。

`chat_controller.dart` 从 3320 行降至 3237 行；`android_device_tool.dart` 从 3401 行降至 3031 行。行数变化来自职责迁出，不能解释为全项目净删掉相同数量的代码。

### 工作区与知识库

- Git 工作区快照复用 Git 的 tracked/untracked 文件清单，遵守忽略与反向忽略规则；非 Git 目录在递归前排除缓存目录，不再先枚举全部后过滤。
- 选中的独立项目若位于父仓库忽略的临时目录中，不套用父仓库的空索引；Git worktree 的 `.git` 文件仍可识别。
- 知识库在 SQLite 中筛选全局与当前项目的文档/分块，再构建 BM25 索引；保留项目隔离、来源元数据及 revision 失效机制。
- 未声称测得具体性能提升比例；语义与范围已通过定向测试。
