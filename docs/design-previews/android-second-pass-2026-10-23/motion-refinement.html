让操作更连贯，让内容更稳定

建议统一重做动效节奏，沿用刚确定的简约聊天界面。把“可见的弹跳与装饰”改成“及时反馈、位置连续、状态清楚”。下面保留最初的 HTML 示意，不是 App 实录。第一版现已落地，查看实际 App 录屏与实施范围。

发送：一次连续动作

气泡在落点轻移 6dp、淡入 180ms；避免文字飞行、缩放、光圈同时出现。用户消息立即入列，动画不等待接口。

导航：层级一眼看懂

只移动侧栏，主页面留在原位。菜单打开约 240ms，关闭约 160ms；实际 App 的边缘手势需要跟手，不套二次播放。

选择：反馈短，收起快

面板上移与遮罩同步。选中项立即显示勾选，再收起面板；不逐条错开出现。重要审批须保留确认过程，不能照搬自动关闭。

减少动态效果取消位移、缩放、光效及循环；状态及时直接更新。遵守系统设置与现有 full / reduced / off 语义，保留必要文字和交互。

是否整体大改？

推荐做“动效规则统一”，不要再次更换页面风格。现有工程已经具备时长、弹簧、分档、生命周期与减少动态效果的基础，保留它们，在 Android 分支收敛表现即可。桌面与专用画布独立验收。

顺序实施范围完成判断
第一步聊天发送、助手入场、流式高度、滚动和键盘衔接。同一动作只有一个视觉重点；快速连发不跳位；阅读历史不被拉走。
第二步统一抽屉、Sheet、页面返回和手势中断。快速打开关闭无重影；返回顺序正确；草稿、焦点和滚动位置保留。
第三步收敛通用按压、状态呼吸、列表入场与工具详情。待机与完成态无装饰循环；退出页面停止控制器；无障碍设置立即生效。

验收需要同时看“舒服”和“可靠”

检查普通手机、320dp 窄屏、大字体、深色模式、长回复、附件、审批和暂停恢复。模拟器适合核对布局与行为；性能使用真机 profile 模式检查 UI / raster 帧、重建与长列表，不能把 debug 模式的卡顿直接当作发布性能。

循环动画只留在确实进行中的局部指示；不新增整页持续模糊、光斑、扫描文字。过渡可中断，动画不阻塞发送、授权或返回。
