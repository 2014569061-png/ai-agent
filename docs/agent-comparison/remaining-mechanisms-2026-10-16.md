2026-10-16。接续前两阶段，保留已完成的上下文摘要、头尾截断、读前写、自动验证和有限修复闭环。

## 已接入的行为

| 原缺口 | 本轮实现 | 入口 |
|---|---|---|
| 只有全文搜索 | `repo_map` 使用 Dart analyzer AST 输出声明、所属类型、文件、行号和内容哈希；按名称过滤；内容变更使解析缓存失效 | 聊天、后台任务和修复工具白名单 |
| 无补丁格式 | `apply_patch` 接受单文件多 hunk unified diff；全部上下文和行数验证后才调用受保护的写入工具 | 聊天、后台可写任务和修复工具白名单 |
| 子任务只有串行字符串 | `sub_agents` 同时启动最多三个子任务，逐项返回 id、成功状态、错误码和有界摘要；失败不抹掉其他项结果 | 聊天委派 |
| 折叠规则散落 | `TranscriptViewPolicy` 集中四种状态的默认展示字段；工具、计划、推理和错误技术详情读取策略 | 聊天组件 |

### 索引

扫描有文件数量、遍历数量、单文件大小和累计读取量限制，跳过常见构建目录、生成文件和目录中的符号链接。解析在 isolate 执行。索引不会登记为 `read_file`，因此不能绕过读前写保护。

第三阶段最初仅有 Dart 声明索引。接续收尾已增加 Python/JavaScript/TypeScript 词法索引、候选调用边与 Git 标准忽略规则，详见末节；仍不是编译器级语义引用解析，也没有移植 Aider 的完整图排序。

### 补丁

严格匹配目标路径、旧内容、hunk 行数与顺序；任一 hunk 不匹配，所有 hunk 都不写入。支持 CRLF 和显式末尾无换行标记。沿用文件新鲜度检查、写入审批、基线保存及修改元数据。

这里的“全部验证后写入”仅针对一个文件的修改块；不意味着跨文件事务或底层磁盘写入原子性。创建、删除、移动继续使用对应工具。

### 并行子任务

所有参数在启动前统一验证。每项独立上下文，只允许读取、搜索、索引、计算、时间和 JSON 查询；不提供写入、终端、MCP 扩展或嵌套委派。父运行的取消令牌传入子任务。异常返回结构化失败，不将异常原文作为成功摘要。

隔离方式是“独立上下文 + 共享只读工作区”，不是独立 worktree 或文件快照。主任务或外部编辑器仍可能改变子任务读取的文件。子任务结果进入父工具记录，没有独立的持久子任务调度队列。

每项 `maxTokens` 为单次模型输出上限（500–8000），一批各项上限之和不超过 12000；它不是包含输入、重试和多轮调用的累计 token 上限。修复了显式 2048 被旧默认值策略放大的问题，以及后台累计 usage 事件重复相加的问题。

### 展示策略

工具待审批时强制展开；执行时展开；完成后根据紧凑模式和条目数量折叠。未确认、暂停或失败的计划展开，已完成计划收起。推理进度是否精简、推理正文及错误技术详情的初始展开状态统一读取策略字段。用户手动展开状态仍由组件维护。

## GitHub 借鉴依据

- [Aider repo map 实现](https://github.com/Aider-AI/aider/blob/main/aider/repomap.py)：借鉴先抽取代码符号、再提供有界仓库上下文的思路；本项目使用 Dart analyzer，未复制其排名实现。
- [Aider unified diff coder](https://github.com/Aider-AI/aider/blob/main/aider/coders/udiff_coder.py)：参考补丁作为编辑契约的做法。本项目采用严格上下文匹配，未移植模糊应用算法。
- [Dart analyzer parseString](https://pub.dev/documentation/analyzer/latest/dart_analysis_utilities/parseString.html)：实际 AST 解析 API。`analyzer` 从已解析的传递依赖提升为直接运行依赖。

## 接续收尾：多语言候选引用图

2026-10-16 核验了上一轮已落盘但未完成收尾的实现，没有重写现有机制：

- `repo_map` 覆盖 Dart、Python、JavaScript 和 TypeScript。Dart 声明与调用使用 analyzer AST；其他三种语言使用有界词法扫描，过滤注释和字符串中的伪声明。
- `source_symbol_index.dart` 按语言族和调用名称建立候选边。JavaScript/TypeScript 共享语言族；同名声明保留多个目标并标记 `ambiguous`，不会伪装成确定的类型绑定。候选引用数量参与声明排序。
- `git_index_selection.dart` 通过 `git ls-files --cached --others --exclude-standard` 选择已跟踪及未忽略文件，支持嵌套忽略与重新包含。Git 不可用、超时或输出超限时，明确返回 `builtin_fallback`，不伪造空索引成功。
- 保留文件数、读取量、缓存、词法 token、声明和引用的上限；返回截断标记。内容哈希驱动缓存刷新，索引不授予写入许可。
- `test/repo_map_languages_test.dart` 的 4 项测试通过，覆盖字符串/注释过滤、混合语言歧义、缓存刷新及 Git 忽略规则；连同补丁、运行控制、隔离子任务等 9 个测试文件共 103 项通过，相关 10 个源码和测试文件静态分析无问题。

边界：这是四种语言的**候选引用图**，不是所有语言的编译器/语言服务器。暂不支持 JSX/TSX、模板插值的完整解析、Python 动态绑定、跨语言 FFI 解析或 Aider 式全图排名；需要读取源码核实候选结果。
