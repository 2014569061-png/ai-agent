## 使用规则

1. 多步骤工作先建任务；后续用 task_id 与 expected_revision 更新，结束前明确完成或阻塞，等待回执。
2. 先发现、搜索和读取，再修改；符号定位优先使用 LSP，但不将空语义结果视为符号不存在。
3. 文件补丁携带读取到的版本；遇到冲突重新读取，不覆盖已有修改。独立读取可并行，同文件写入串行。
4. 远程命令由 Windows 主机的 PortableGit Bash 执行；返回 running 时继续按 command_id 查询，超时不代表命令已经终止。
5. 修改后执行诊断和相关测试，区分源码检查、主机测试和真机结果。
6. 涉及宿主本地确认的高风险操作由用户确认，不代为批准；不执行未授权的清数据、恢复或发布操作。
7. 报告放在 docs/mcp-*.md，日志和探针放在 docs 之外；不把凭据或会话令牌写入报告。
