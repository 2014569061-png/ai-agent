# NEXUS 桌面深层页面重构

日期：2026-10-16

## 交付范围

在上一轮桌面工作台 UI 改版基础上，为以下页面提供桌面专用结构：

1. 服务商管理：配置、当前默认与内置预设分开筛选；名称/模型/协议搜索；配置编辑、设为默认、删除保留原持久化入口。
2. 模型选择：名称/ID 搜索，工具/视觉/JSON 能力筛选，名称或上下文排序；选择仍向调用页面返回真实 Model ID，不自动保存服务商配置。兼容 API 远端列表与手动模型入口保留。
3. MCP 管理：配置启用状态与最近手动测试结果明确分离；显式测试、编辑、启用/停用及删除；STDIO 添加/编辑仍遵循原开关，筛选项仅在已解锁或已有 STDIO 配置时显示。
4. Agent 管理：名称及系统指令搜索、名称/执行步数排序；描述生成草稿、手动创建和编辑权限沿用原流程。
5. 知识库：来源筛选、名称/更新时间/分块数排序；文件上传、粘贴、检索开关及删除确认保留。
6. 长期记忆：来源/高重要度筛选、更新时间/重要度排序；完整内容可选择复制，保留编辑、删除确认与全局开关。
7. 服务商与 Agent 编辑器：桌面宽屏增加只读配置摘要，限制表单宽度；小窗口回落单列；保留保存、风险提示及放弃修改确认。

公共组件：

- `lib/presentation/widgets/desktop_editor_layout.dart`

## 状态与安全边界

- 内置服务商模板不作为已配置连接显示。
- “已填写密钥”不等同于“连接成功”。新输入密钥明确标记为需保存后才写入安全存储。
- MCP “已启用配置”不等于在线；测试结果仅描述最近一次显式测试，不做持续连通性承诺。
- URL 概览去掉用户信息、查询参数与片段，不在资源摘要中展示 API Key。
- 能力标签来自预设或服务返回，并非实际调用验证结果。
- 筛选与排序作用于已加载数据的副本，不改变源数据顺序、不写回数据库。
- 默认不自动测试 MCP、不授予 Agent 新权限；危险删除继续使用原确认流程。
- MCP 与服务商加载异常提供重试状态，不把读取失败显示成“没有配置”。
- 移动端继续使用原页面分支；本轮未改数据库结构、依赖或运行引擎。
