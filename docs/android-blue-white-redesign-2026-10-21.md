# NEXUS Agent Android 蓝白轻盈设计方案

日期：2026-10-21。阶段：设计交付，尚未修改应用 UI，也未执行模拟器视觉验收。

本方案依据当前工作区源码、用户提供的四张参考图和已确认的偏好：对话优先、小艺助手式柔和光感、减少同时出现的控件与说明。以下布局、数值和组件均为本项目的设计建议。

## 1. 设计方向与参考图评审

### 1.1 方向

以图 2 的助手首页为主要视觉参考，以图 4 的项目分组为列表参考。图 3 提供执行过程的信息层级参考，图 1 提供待处理事项的优先级参考。

视觉重点依次是当前内容、下一步操作、运行状态。白色与浅冷灰承担主体，蓝色承担动作和选中状态。柔和光感只在空白首页的标识周围或浮层边缘出现，文字与内容容器保持实色。首页轻盈，工作页面紧凑而易读。

### 1.2 四图的具体取舍

| 参考图 | 保留 | 调整 |
| --- | --- | --- |

四图的底部导航在名称、位置、图标、选中样式上互相冲突，不能作为一套界面直接照搬。统一为“助手 / 任务 / 工作区 / 我的”，位置固定。

### 1.3 核心原则

1. 对话首屏优先出现输入区和简短欢迎语；模型未配置时提供一个直接的配置入口。
2. 常用操作直接可见，设置和原始记录逐级展开。折叠内容必须有明确名称与状态摘要。
3. 一种信息只在一个主要位置解释；避免顶部、消息内、输入框上方同时重复同一运行状态。
4. 列表负责扫描，详情负责理解，审批面板负责决策。
5. 简化外观时保留功能可达性、授权边界和真实状态。

## 2. 全功能信息架构与入口映射

### 2.1 当前源码核对结论

- `navigation/mobile_shell.dart` 已有助手、任务、工作区、我的四个入口，分别加载 `ChatPage`、`JobsInboxPage`、`ProjectPickerPage` 和 `SettingsPage`，每个入口有独立导航栈。
- `chat/widgets/chat_catalog_drawer.dart` 同时承担会话、仪表盘、Agent、项目、工具等入口；`chat/chat_page_sheets.dart` 中还有会话工具面板，存在信息分散。
- `settings/extensions_page.dart` 汇集 Agent、提示词、技能、MCP、工作流、环境、用量和日志。
- `settings/data_management_page.dart` 汇集知识库、记忆、成果、个人上下文、提醒、审计及数据备份。
- `jobs/jobs_inbox_page.dart` 分别读取未读收件箱、近期任务、独立的待处理任务。打开收件事项会标为已读，标为已读不会解决任务。
- `projects/project_home_page.dart` 已提供文件、终端、任务、产物及开发工具相关入口。

这是页面和入口的源码核对；实际设备运行、不同权限条件及 ARM64 运行时能力仍需在实施阶段验证。

## 3. 视觉与交互规范

### 3.1 色彩

| 语义 | 浅色建议值 | 使用位置 |
| --- | --- | --- |
| 页面背景 | `#F7F9FC` | 列表页、设置页、工作区 |
| 对话背景 / 内容表面 | `#FFFFFF` | 阅读区域、分组容器 |
| 主色 | `#0A59F7` | 发送、主要操作、选中图标 |
| 浅蓝选中背景 | `#EAF2FF` | 用户消息、筛选与选中项 |
| 主文字 | `#182230` | 标题、正文 |
| 次级文字 | `#667085` | 时间、摘要、辅助信息 |
| 分隔线 | `#E8EDF4` | 分组内部，仅用于分隔 |
| 成功 | `#107C41` | 完成图标与文字 |
| 待关注 | `#9A6700` | 待核实、部分完成、审批提示 |
| 错误 / 危险 | `#C62828` | 失败与破坏性操作 |

蓝色不包办所有状态。完成为勾加“已完成”，审批为盾牌加“待审批”，失败为错误图标加“失败”。部分完成不得伪装为成功。

柔光限定在首页标识附近约 160–220dp 区域，低透明度静态渐变即可；正文下面不铺光纹。卡片默认无阴影，输入区与浮层允许极弱阴影。信息容器使用实色，避免层叠背景模糊。

保留现有深色选择：页面 `#111722`、内容 `#1A2230`、正文 `#ECF1F8`、次级文字 `#A7B2C2`、强调色建议 `#8EB7FF`。逐项核验文字、禁用状态与选中背景的对比度。跟随系统与明确的浅色/深色选择继续有效。

### 3.2 排版、尺寸与布局

| 项目 | 规范 |
| --- | --- |
| 字体 | 中文优先系统无衬线；英文与中文保持协调；不为外观强制下载额外字体 |
| 主入口标题 | 28sp / 600；向上滚动后可收敛为 20sp 工具栏标题 |
| 二级页标题 | 20–22sp / 500–600 |
| 首页欢迎语 | 28sp / 500；窄屏和大字体允许两行 |
| 正文 | 16sp / 400，行高约 1.55 |
| 列表标题 / 小节标题 | 16sp / 500；避免整屏粗体 |
| 摘要 / 时间 | 14sp / 400；关键决策信息不缩成脚注 |
| 水平边距 | 页面 20dp；内容容器内部 16dp |
| 间距体系 | 4 / 8 / 12 / 16 / 24 / 32dp |
| 双行列表 | 最小 76dp；内容决定高度，大字体自然增长 |
| 圆角 | 分组 20dp，消息 18dp，输入框 26dp，底部面板 28dp |
| 图标 | 常规 22–24dp，统一圆润线性风格；选中可实心 |
| 触摸目标 | 至少 48×48dp；视觉图标可小于点击区域 |
| 底栏 | 内容区约 64dp，加系统安全区；选中图标置于轻薄浅蓝背景，标签仍清晰 |
| 主按钮 | 高度最小 48dp，文字与图标居中 |

按钮和筛选项不使用固定宽度硬塞中文。页面以 360–430dp 手机宽度为主要设计范围，320dp 与文字缩放 200% 下仍能阅读、滚动和完成关键操作。长路径显示文件名与可复制全路径；代码和终端使用横向滚动，不强行断开命令含义。

### 3.3 动效和系统行为

- 选择与按压约 180ms，页面或面板过渡约 220–260ms；运行转圈只用于真实运行状态。
- 尊重减少动态效果设置，关闭装饰位移与循环柔光，状态变化保留即时文字反馈。
- 键盘打开时隐藏底栏，将输入框与当前会话操作置于键盘上方；关闭键盘后恢复。避免外层和内层各计算一次键盘 inset。
- 输入框从约 88dp 随输入增长至可用高度的一部分，随后内部滚动；附件行可移除，不遮挡发送。
- 用户正在阅读早期消息时，流式更新不强制拉到底部；显示“回到最新”。
- 返回遵循当前页栈；退出编辑时沿用未保存确认，弹层关闭不能顺带更改模式。
- 屏幕阅读器朗读按钮名称、选中状态、任务状态；进度播报限制频率，避免每个流式字符触发。

| 计划区 | 简短计划、当前步骤、确认入口 | 待确认、已确认、执行中、调整后重新确认 |
| 审批面板 | 操作、命令/目标、影响、范围、允许与拒绝 | 待审批、验证身份、已处理、超时、请求已变化 |
| 结果条目 | 成果名称、类型、真实可用动作 | 可用、保存中、缺失、失效、部分结果、导出失败 |
| 状态文字 | 图标与短标签 | 各类任务状态；未知状态不显示成功 |
| 底部面板 | 拖动条、标题、列表或表单、安全区 | 短列表、长列表、键盘、需显式确认的变更 |
| 表单字段 | 常驻标签、当前值、字段级说明 | 默认、聚焦、错误、禁用、敏感信息遮罩 |
| 异步内容 | 简洁骨架或进度、保留已读内容 | 初始加载、刷新、空数据、失败、重试 |
| 轻提示 / 行内错误 | 简短动作反馈；需要处理的错误常驻 | 成功、错误、可重试、离线、旧数据显示 |

加载失败的计数显示“读取失败”或“未读取”，不能变为 0。更新中可显示上次数据并说明时间。任务变为已读只改变未读标记，待处理状态仍由真实任务状态决定。

审批面板使用“允许本次 / 拒绝”，按现有策略决定可用选项。终端逐次确认、前台批准、高风险身份验证继续有效。原始参数可展开，但做决定必需的命令、目标和影响不能全部折叠。

## 5. 五个主要界面的具体设计

### 5.1 助手首页

首屏由三部分构成：轻薄顶部栏、居中的欢迎内容、底部输入区。顶部为“会话图标 / NEXUS 或当前 Agent / 新对话”。首页标识为 64–72dp 的简单光感形状，周围仅局部淡蓝柔光。

欢迎语：“今天想一起完成什么？”；辅助文案最多一行或两行：“把问题和任务交给我，一起往前推进。”其下最多三个建议：“整理资料 / 分析项目 / 创建 Agent”。空间不足时自然换行，不压缩字体。

点击“整理资料”填入可编辑建议，不静默读取本机资料；“分析项目”在未选项目时先选择项目；“创建 Agent”进入现有描述创建草稿流程。普通建议不自动发送或执行。

输入框第一行为“说说你想做什么…”，第二行为加号、当前模型简称与发送。空输入发送不可用。模型未配置时，模型位置显示“配置模型”；首页只出现一处简短提示。没有 API Key 时不假装可以发送。

- 主操作：输入并发送。
- 次级入口：会话抽屉、Agent 选择、模型选择、附件。
- 默认折叠：执行模式、思考、计划、审批策略、技能、浏览器、用量与日志。
- 首屏避免：统计数字、运行环境清单、长篇功能说明、工具宫格。

### 5.2 进行中的对话

顶部仍可打开会话抽屉，中间显示会话标题，右侧更多。用户浅蓝气泡靠右；助手以左对齐正文为主。每个连续助手回合仅出现一次小身份标记，正文不重复套卡片。

示例顺序：

1. 用户：“帮我看看这个项目，整理一下可以改进的地方。”
2. 助手：“我会先查看项目结构，再整理关键问题与建议。”
3. 执行摘要：“正在分析主要模块 · 已完成 1/2 项”，点开可见“读取项目结构：已完成 / 分析主要模块：进行中”。
4. 正文小节“初步发现”，两条简短建议，继续流式更新。
5. 保存成功后出现“项目分析.md”结果行，提供查看与导出。没有真实文件时仅展示正文。

仅在真实存在可计数步骤时展示 1/2 等分母；否则只显示动作与状态。费用、耗时和 Token 放入会话更多的“用量与上下文”。不展示未对用户开放的内部推理；沿用已有公开计划、简短摘要和工具记录。

运行时输入框右侧为单一的“停止”动作，使用中性深色方形图标或轻底按钮；破坏性操作才使用强烈红色。暂停、继续、重试根据真实状态出现。新消息能否发送或排队遵循当前业务实现，不因设计图新增队列能力。

- 主操作：阅读回复；运行时可停止，需要决策时处理审批。
- 次级入口：更多、附件、模型、消息长按、展开执行记录。
- 默认折叠：完整工具参数与输出、历史步骤、旧计划、指标、上下文详情。
- 例外：待审批摘要不能被折叠到不可发现的位置；当前任务失败时直接展示原因与可用恢复动作。

### 5.3 任务页

顶部为“任务”、搜索和更多。页签采用“待处理 / 最近任务 / 收件箱”，默认待处理；有未读事项时在收件箱显示真实未读计数，底栏可用单个小圆点提示。

待处理列表按需要注意的程度和时间排序；同优先级保持稳定。每项显示任务名、一行下一步说明、状态、关键时间与详情箭头。状态示例：“待审批 / 待核实 / 已暂停 / 失败 / 部分完成”。待审批仅使用细微暖色图标，不给整张列表铺橙色。

示例：“确认终端操作 / 项目分析需要执行一条命令 / 待审批 · 2 分钟前”。点击进入任务或审批详情，查看完整命令再决策。不得在看不到命令时一键允许。

最近任务用于浏览实际近期记录；收件箱用于阅读动态。收件箱更多菜单可“全部标为已读”，反馈“已标为已读，待处理事项仍保留”。待处理为空时显示“暂时没有需要你处理的事项”，提供“查看最近任务”，不宣称所有任务均已成功。

- 主操作：打开并处理一条任务。
- 次级入口：搜索；更多内定时任务、工作流、开发任务记录、刷新。
- 默认折叠：完整日志、原始输出、技术字段、列表范围说明。
- 详情页：标题和真实状态 → 当前需要做什么 → 简短结果 → 运行步骤 → 关联会话与成果；已完成时间线默认收起。

### 5.4 工作区与项目详情

工作区顶部为“工作区”和加号；加号展开“新建项目 / 从目录导入 / 从模板创建”。下方是“搜索项目”。最近项目展示真实名称、可读类型、更新时间；不展示不存在的项目分类。保留全部项目入口。

项目列表参考图 4：同一白色分组，行高约 80dp，40dp 浅蓝图标承载区与统一文件夹图标。成果中心作为单独一行入口，摘要“查看已保存的成果”。不额外增加营销式说明。

点击项目行进入项目主页，明确展示项目名与目录摘要，并提供“在助手中继续”。这与当前直接选择项目进入聊天的路径不同，实施时必须显式复用实际项目选择逻辑；文件与任务操作必须使用当前展示项目的 ID。聊天中的“切换项目”仍可选择后直接返回会话。

项目主页：顶部项目名和更多；“文件 / 任务 / 成果”作为内容切换。“项目工具”提供 Git、变更集、开发工作台、终端、环境和适用的预览入口。终端和代码编辑可使用全屏专注页面。

只在工具缺失或用户准备运行时展示环境提示，不常驻完整 SDK 检测列表。静态网页直接提供现有网页预览与交付，不强推 Linux 安装。远程连接页面按真实连接诊断能力命名。

- 主操作：首页打开项目；项目内在助手中继续或打开文件。
- 次级入口：新建、导入、模板、全部项目、成果中心、项目工具。
- 默认折叠：完整路径、环境明细、Git 技术字段、历史日志、远程连接诊断。
- 文件处理：名称优先，支持查看完整路径和复制；不可访问时提供重新授权与重试。

### 5.5 我的

顶部只显示“我的”和设置搜索图标。采用白色圆角分组列表，不添加虚构的账户、头像、会员或云同步。

分组顺序：

1. 模型与助手：模型服务、Agent、提示词库。
2. 工具与扩展：技能、MCP、工具与执行策略、工作流、开发环境、设备与权限。
3. 个人数据：长期记忆、个人上下文、知识库、备份与恢复、数据管理。
4. 用量与诊断：用量与费用、运行分析、运行日志、审计日志。
5. 外观与系统：外观、字体、语言、系统助手、系统编辑器连接。
6. 关于与帮助：版本与更新、帮助与反馈、服务协议与隐私。

标准手机首屏优先显示前两组及个人数据的开头，其余自然滚动；大字体下允许更多滚动，不压缩行高。“技能 3 个”等摘要只在真实读取成功时展示。首页不展示整屏调试状态。

- 主操作：进入对应配置或管理页；无悬浮主按钮。
- 次级入口：设置搜索、关于与帮助。
- 默认折叠：配置表单、原始诊断、设备细项；清除数据在数据管理页底部独立分组并保留确认。
