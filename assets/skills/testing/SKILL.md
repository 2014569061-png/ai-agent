# 测试策略

## 测试分层

先确定行为契约，再选择最小合适的测试层级：纯函数用单元测试，交互用 Widget 测试，跨层流程用集成测试。

每个关键功能至少覆盖：成功、空输入、边界值、非法输入、异常和重复执行。测试应验证用户可观察行为，而不是脆弱的内部实现细节。

保持测试隔离：清理临时文件和数据库，注入时钟、网络和平台依赖。修复缺陷时先增加能复现问题的回归测试，再修改实现。完成后运行聚焦测试，再运行完整套件。
