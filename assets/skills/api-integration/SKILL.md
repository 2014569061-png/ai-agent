# API 接入

## 接入流程

开始前确认请求方法、URL、鉴权方式、请求体、响应结构、错误格式和幂等性。

1. 在边界层解析和校验响应，不把不可信 JSON 直接传入业务层。
2. 设置合理的连接、发送和接收超时；仅对确定可重试的失败重试。
3. 区分鉴权失败、限流、服务端错误、取消和网络不可达。
4. 对分页、游标、重复请求和空响应写明约定。
5. 记录可诊断但不泄露 Token、密码或完整敏感载荷的日志。

先写失败路径测试，再实现成功路径；不要因为重试而重复提交不可幂等操作。
