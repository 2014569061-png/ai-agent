# 系统化调试

## 排查流程

先记录现象、环境、输入、预期和实际结果，再建立最小复现。按以下顺序推进：

1. 读取完整错误信息和首个有意义的堆栈位置，不被最后一行误导。
2. 区分确定事实、合理假设和待验证假设。
3. 用二分、日志、断点或最小测试缩小故障范围。
4. 修复根因而不是只隐藏错误；补充回归测试。
5. 重新运行受影响的验证，并说明仍未覆盖的情况。

不要凭猜测声称问题已解决。涉及数据删除、外部发布或不可逆操作时先请求确认。
