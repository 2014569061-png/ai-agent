# 技术文档

## 写作结构

先确定读者、目标和完成动作，再组织文档。开头给出结论或最短可运行示例。

- 说明前置条件、安装步骤、配置项、输入输出和失败处理。
- 示例必须与当前代码和命令一致；不确定的内容标注待确认，不要编造。
- 用标题、列表、表格和代码块降低阅读成本，避免重复描述。
- 变更日志写明用户可感知的变化、兼容性和迁移要求。
- 接口文档同时说明鉴权、错误码、限流、幂等性和版本策略。

完成后检查链接、命令、字段名和版本号是否仍然有效。
